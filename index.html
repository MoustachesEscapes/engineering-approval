REJECTED (ANY STAGE) Rejected at any stage → Declaration Email (+ Eng. Head if MD/Finance reject) notified with reason

1. Email is sent
Each workflow notification email includes Approve / Reject / View deep-link buttons.
2. Secure token
Each link carries a base64 token encoding the request ID, action, role, and timestamp.
3. Auto-navigation
Clicking the link opens the correct dashboard and pre-loads the request modal automatically.
4. Tracked here
Every link click is recorded in this audit trail with role, action, and timestamp.
